# 第18周趋势总结

日期范围：2026-04-27 至 2026-05-03

## 精选10条

### 1. Ghostty 宣布离开 GitHub，迁移至自建平台
- 来源：Hacker News（3244分 · 959评论）
- 摘要：终端模拟器 Ghostty 作者 Mitchell Hashimoto 宣布项目将从 GitHub 迁移到自建的 Git 托管平台。这是继去年 gitu 和 gitte 之后又一个离开 GitHub 的知名项目，引发了关于"代码平台中心化"的激烈讨论。评论中有人指出 GitHub 最近的 UX 改动（如 issue 链接改为弹窗）是导火索。

### 2. 我花 3 万美元买了 Friendster——然后我在做什么
- 来源：Hacker News（1041分 · 556评论）
- 摘要：一位开发者分享了他购入已关闭的社交网络 Friendster 域名后的计划。他打算用这个拥有2000万用户数据的"遗产"做点什么。文章引发了大量关于早期社交网络、数据所有权和怀旧的讨论。

### 3. Zed 1.0 正式发布：GPUI 驱动的下一代代码编辑器
- 来源：Hacker News（1015分 · 327评论）
- 摘要：Zed Industries 发布了 Zed 1.0 正式版。这个用 Rust 和 GPUI（自研 UI 框架）构建的代码编辑器主打高性能，声称启动速度远超 VSCode。1.0 版本的发布标志着该项目从beta阶段正式走向生产可用。

### 4. 西方忘记了如何制造东西，现在连如何写代码也在遗忘
- 来源：Hacker News（974分 · 637评论）
- 摘要：文章回顾了西方制造业外包的历史，以及这种趋势如何延伸到软件工程。提到欧盟承诺向乌克兰提供100万发炮弹但年产能仅23万发的尴尬现实，以及软件行业对" caretaker class "的依赖。引发了对技术去全球化的深度思考。

### 5. OpenAI 官方博客：Goblin 家族从何而来
- 来源：Hacker News（977分 · 584评论）
- 摘要：OpenAI 官方发布的关于 GPT-4o 等模型训练数据中" goblin "相关问题的技术解释。虽然标题看似轻松，但实际是关于预训练数据中某些模式形成原因的深度技术文章，阅读量在本周位居前列。

### 6. Microsoft 与 OpenAI 结束独家合作及收入分成协议
- 来源：Hacker News + Bloomberg（496分 · 422评论）
- 摘要：据彭博社报道，微软将停止与 OpenAI 的独家合作及收入分成安排。这一重大变化意味着 OpenAI 未来可以更自由地与其他云服务商合作，而微软则可能将更多资源转向自研 AI 模型。评论中有人分析了此举对 Azure AI 业务的影响。

### 7. Zig 项目严苛的"反 AI 贡献"政策引发争议
- 来源：Hacker News（595分 · 369评论）
- 摘要：Zig 语言项目维持着目前主流开源项目中最严格的 AI 政策——不接受任何使用大语言模型生成的 issues、PRs 或代码。文章引用了项目维护者的详细解释，但社区反应两极分化，部分人认为这是原则性立场，也有人认为过于极端。

### 8. LocalSend：开源跨平台 AirDrop 替代品
- 来源：Hacker News（611分 · 204评论）
- 摘要：LocalSend 是一个开源应用，允许用户在任意设备间无线传输文件，支持 iOS、Android、Windows、macOS、Linux。与苹果 AirDrop 不同，它不依赖生态系统绑定。本周获得了大量关注，Star 数快速增长。

### 9. 荷兰央行抛弃 AWS，选择 Lidl 旗下云服务
- 来源：Hacker News（248分 · 93评论）
- 摘要：荷兰中央银行（DNB）宣布与 Lidl 母公司的 IT 部门 Schwarz Digits 签署大型合同，将数据迁移至其云平台。此举旨在减少对美国大厂的依赖，是欧洲央行系统"去 AWS 化"的又一个案例。

### 10. Linux 7.0 导致 PostgreSQL 性能回退：预抢占回归问题解析
- 来源：Hacker News（95分 · 37评论）
- 摘要：Linux 7.0 内核的一个预抢占机制变更导致 PostgreSQL 性能大幅下降。分析文章深入解释了内存屏障、CPU 缓存一致性和内核调度之间的关系。这类底层性能问题本周引发了不少内核和数据库开发者的关注。

## 本周总结

本周 HN 社区最热的话题集中在三个方向：**平台信任危机**（Ghostty 离开 GitHub、GitHub Copilot 改为按用量计费）、**AI 争议话题**（Zig 反 AI 政策、Claude Code 拒绝特定关键字、ChatGPT 广告系统），以及**开源生态变化**（LocalSend 崛起、Zed 1.0 发布）。整体来看，开发者对大平台的不满情绪在上升，去中心化和自托管方案获得更多共鸣。技术层面，Rust 生态的安全问题（44 CVEs）和 Linux 7.0 的回归 bug 提醒我们"现代系统的复杂性"仍是挑战。
