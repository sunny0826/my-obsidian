## 精选10条

### 1. 国产开源大模型「双王炸」：智谱 GLM-5.2 与 MiniMax M3 同周发布
- 来源：AI 日报 · 公众号：智谱 + MiniMax · 2026-06-15/16 · ⭐️ 9.0/10
- 摘要：智谱 GLM-5.2 全面开放 1M 上下文并下周以 MIT 协议开源，定位 Coding 与长程任务；MiniMax M3 同步开源 428B 总参/23B 激活 MoE 模型，配套 MSA 稀疏注意力论文，在 Artificial Analysis、GDPval-AA、Code Arena、Vals.AI 多项榜单登顶。国产开源从「追赶」切换到「领跑」的开源权重赛道。

### 2. DeepSeek 完成首轮外部融资，估值超 500 亿美元
- 来源：AI 日报 · The Decoder · 2026-06-16 · ⭐️ 9.0/10
- 摘要：DeepSeek 首次接受外部投资即超 74 亿美元，500B+ 美元估值，引入 LP 投资结构、5 年锁定期，背后站腾讯、宁德时代、华为。再次确认「国家级资本 + 头部产业资本 + 5 年不退出」的中国 AI 抱团模式，OpenAI/Anthropic 之外最重磅的融资事件。

### 3. SpaceX 以 600 亿美元股票收购 AI 编程公司 Cursor
- 来源：AI 日报 · TechCrunch · 2026-06-16 · ⭐️ 8.0/10
- 摘要：SpaceX 在 IPO 后数日宣布以 600 亿美元股票收购 Cursor（AI 编程 IDE 头部玩家），瞄准 xAI 在编码 Agent 的能力补齐。AI 编程工具赛道首次出现「航天巨头收购 IDE」的资本奇观，预示 xAI 与 OpenAI/Anthropic 的编程 Agent 战全面升级。

### 4. Anthropic Project Fetch 第二阶段：Claude Opus 4.7 自主完成任务，速度比人类团队快约 20 倍
- 来源：AI 日报 · Anthropic Research · 2026-06-18 · ⭐️ 9.0/10
- 摘要：Anthropic 发布 Project Fetch Phase Two，Claude Opus 4.7 在自主机器人控制任务上较人类团队快 20 倍、较非 Claude 团队快 37 倍，代码量少 10 倍。标志 AI 从「辅助人类」正式跨越到「自主执行」的范式分水岭，是具身智能研究的关键里程碑。

### 5. NVIDIA GEAR 实验室 ENPIRE：8 个 Codex 智能体自主控制机器人完成物理实验
- 来源：AI 日报 · @DrJimFan · 2026-06-17 · ⭐️ 9.0/10
- 摘要：NVIDIA GEAR 发布 ENPIRE，8 个 Codex 智能体并行控制 8 台机器人完成物理实验，引入硬件安全护栏、冻结视觉奖励函数（防 reward hacking）、新型效率指标。首个具备「多智能体 + 物理硬件 + 安全机制」三位一体的自主科研框架，向「自主科学」迈出实质一步。

### 6. Google 发布 Agentic Resource Discovery（ARD）开放规范：AI 智能体时代的「robots.txt」
- 来源：AI 日报 · Google Developers Blog · 2026-06-17 · ⭐️ 9.0/10
- 摘要：Google 发布 ARD 开放规范，让 AI 智能体能在 Web 上发布、发现并以密码学方式验证彼此能力，对标 HTTP/robots.txt/schema.org 级别的「互联网奠基性标准」。一旦被生态广泛采纳，将成为 Agent 网络的目录基础设施，定义未来 5-10 年 Agent 互操作。

### 7. 安全研究员在 GitHub 发现 1 万个分发木马的仓库
- 来源：HN 日报 · Hacker News · 379 分 · 106 评论 · 2026-06-19 · ⭐️ 8.0/10
- 摘要：研究员通过模式化检测脚本识别出 10000+ GitHub 仓库在分发 Trojan 木马，并结合 AI Agent 时代开发者「下载即用」的工作流，指出 GitHub 供应链恶意软件已成规模化问题。HN 讨论提及 Disney 工程师曾「检查过代码看起来没问题」但仍中招的真实案例，凸显供应链安全紧迫性。

### 8. 泄露文件显示 OpenAI 年营收 130 亿但亏损 390 亿美元
- 来源：AI 日报 · Ars Technica（HN 热门中文翻译）· 2026-06-17 · ⭐️ 7.0/10
- 摘要：泄露文件显示 OpenAI 2025 年营收 130 亿美元，但净亏损约 390 亿（含运营亏损约 80 亿），已融资 1220 亿美元、估值 8520 亿。HN 社区对「先融资续命 vs 烧钱做 AGI」展开严肃讨论，被视为 IPO 前的财务透明度压力测试。

### 9. 美政府以「fix this code」为最简单 prompt 封禁 Anthropic Fable 5
- 来源：HN 日报 · The Register · 474 分 · 286 评论 · 2026-06-17 · ⭐️ 7.0/10
- 摘要：研究人员披露美国政府封禁 Anthropic Fable 5 的真正原因：仅靠「fix this code」+ 写测试用例这种最朴素的 prompt 就能让模型输出可利用漏洞的 exploit 代码——并不是传统 jailbreak 而是「顺着修代码的需求自然滑出」。HN 高热度讨论 AI 安全护栏在「协助式越狱」面前的根本脆弱性。

### 10. RFC 10008：新的 HTTP Query Method 正式标准化
- 来源：HN 日报 · rfc-editor.org · 239 分 · 113 评论 · 2026-06-18 · ⭐️ 8.0/10
- 摘要：RFC 10008 正式定义 HTTP Query Method，允许在 idempotent 请求中携带 body 并享受缓存，与 GET/POST/PUT 形成补全。HN 围绕「30 年来首次新增 HTTP 方法」「企业内网遗留系统兼容性」「是否会被 CDN 厂商支持」展开深入讨论，是 Web 协议层少见的高分进展。

## 本周总结

本周是 2026 年 AI 行业「开源 + 资本 + 自主」三线同时爆发的一周。**开源层面**：智谱 GLM-5.2 与 MiniMax M3 同周落地，中国顶级模型在 1M 上下文、Coding、长程任务上同步开源 MIT 协议，标志中国开源权重从「追赶」切换到「领跑」赛道，与 Llama/Qwen 形成全球开源双极。**资本层面**：DeepSeek 500 亿美元估值 + SpaceX 600 亿收购 Cursor + OpenAI 130 亿营收却亏 390 亿，三件事件共同定义「AI 资本进入超大尺度豪赌期」，融资轮次规模已脱离传统 VC 量级。**自主层面**：Anthropic Project Fetch Phase Two 把 AI 自主任务速度拉到人类团队 20 倍，NVIDIA ENPIRE 让 8 个 Codex 智能体并行做物理实验，Google ARD 规范则试图为即将爆发的 Agent 网络铺设「目录基础设施」。与此同时，Fable 5「fix this code」越狱 + GitHub 1 万木马仓库 + OpenAI 财务泄露三条消息在 HN 社区引发严肃讨论，提示当 AI 能力与资本同步爆发时，安全、供应链透明度与商业模式可持续性仍是悬而未决的暗礁。与 W24（法律/伦理/责任）相比，W25 的差异化在于：从「讨论该不该监管」正式进入「AI 自主完成任务、Agent 网络成形、超大资本进场」的工程+商业新阶段。
