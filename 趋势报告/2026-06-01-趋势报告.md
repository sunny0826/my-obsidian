3. **Hackathon 创新竞赛形式**：固定预训练基座 + 禁止蒸馏 + RL 竞争，蒸馏禁令成新焦点
4. **加密圈廉价 LLM 抢占市场**：费用不到主流产品百分之一，低价竞争激烈

### 开源趋势

1. **开源工作流工具爆发**：Codex 开源编排（/dynamic 命令即时启动子 Agent）替代付费工具，免费化浪潮
2. **本地优先安全叙事**：开源 + 逐操作审批比"黑盒云端"更可信（对应 Fazm AI for macOS）
3. **竞品快速涌现**：Sparrow 以"本地单一二进制 + git 检查点 + 可回放"切入 Agent 赛道

### Hermes Agent 生态

1. **OpenClaw 用户流失加速**：多个用户公开"弃 OpenClaw 投 Hermes"，"Apple 体验"类比反复出现
2. **可观测性需求出现**：Perlustron 接入获取 Agent 轨迹可见性（sessions/skills/tool calls），可观测性成下一需求
3. **Sparrow 竞品入局**：标榜"本地 + 模型路由 + git 检查点 + 可回放"，与 Hermes 直接竞争
4. **OAuth 兼容期待高**：社区询问 Claude/OpenAI OAuth token 对第三方 Harness 的支持进度
5. **硬件绑定趋势**：NVIDIA GB10 与 Hermes 组合展现强大算力，硬件赛道升温
